Test without going live

1. Practice run (no TikTok needed)

Turn this on, then go to Live. Scan real products, type a price, and click Simulate sale. It runs through the same matching, stock, and reports as a real order.

Turns off automatically when you reload the page or start a new stream, so it never shows during a real show by accident.

3. Clean up

Deletes every simulated sale and its scan, and puts the stock back. Real orders aren’t touched. Use Undo last scan on Live or No sale on Review for leftover test scans.

2. Check the TikTok connection

Confirms the shop is connected and pulls your 5 most recent orders straight from TikTok. Run through matching treats an order exactly like the live webhook would, against whatever you scanned just before it was placed.

Passcode

Set up Airtable

Creates the Products, Auctions, Orders, and Settings tables in your base. Tables that already exist are left alone, so it’s safe to run again.
